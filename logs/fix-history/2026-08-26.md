## [OFFMARKET-REBUILD-ON-STALE] Viewed /offmarket pages self-heal to the current article — 16:10 AEST
**Symptom (durable gap):** offmarket-artifact.mjs short-circuited on blobExists, so a stale-but-existing blob was served forever and on-demand never rebuilt it. After any article copy change, pages stayed stale until the daily 03:20 pre-warm swept them (up to 24h) and the sweep is a multi-hour grind.
**Fix (rebuild-on-stale):** (1) One shared staleness definition `artifact_fresh(slug,kind)` in publish_offmarket_artifacts.py — blob mtime >= newest generator source mtime — used by BOTH prewarm (has_artifact now delegates) and the poller, so they can't disagree. (2) offmarket-artifact.mjs POST no longer short-circuits on an existing blob; it always enqueues (dedup on in-flight, or completed within 120s, so a busy page doesn't spam the queue). (3) offmarket_artifact_poller.py checks freshness on claim: rebuilds only missing/stale kinds, marks an already-fresh request completed with fresh:true and NO build (one stat()). Net: a page a visitor opens is current within ~10s of a copy change, without waiting for the daily cron.
**⚠ Design trap fixed during build:** source_mtime first globbed ALL *.py/*.json in the article generator dir — but that dir holds unrelated siblings (build_owner_mailer.py, builders, tests, backtests). Editing build_owner_mailer.py bumped the mtime and would have marked every article stale → mass-rebuild churn. Now market-update uses an EXPLICIT input list (build_owner_article.py, charts/factbook/guardrails/variants/subject_trajectory.py + the 5 context JSONs); valuation-report globs its own clean dir. NOT lru_cached so the long-lived poller notices generator changes without a restart. If build_owner_article gains a new import/context file, it must be added to _gen_sources() or its changes won't register as staleness.
**Verification:** poll_once integration tests — fresh slug skipped (no rebuild, fresh:true), stale slug rebuilt (blob mtime advanced). Freshly-rebuilt blobs read fresh under corrected source_mtime.
**Files:** scripts/publish_offmarket_artifacts.py, scripts/prewarm_offmarket_artifacts.py, scripts/offmarket_artifact_poller.py (commit 530d0cf5); netlify/functions/offmarket-artifact.mjs (commit 35b81061). Poller service restarted.
**Recurrence:** Third in the stale-blob family ([PREWARM-STALE-BLOB-FROZEN], [OFFMARKET-MARKET-UPDATE-MASS-REWARM]) — this one closes the root cause.
