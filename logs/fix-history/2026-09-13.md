**Symptom:** PostHog `$exception` on `/off-market/*` — Minified React error #418 (`args[]=text`, server/client text hydration mismatch), unhandled. **Root cause:** `WhatsChangedSection.tsx` computes dates DURING render, in two places: `selectTimeline()` does `const now = new Date()` and `WhatsChangedAnchor()` does `const today = new Date().toISOString().slice(0,10)`. Both feed rendered TEXT — `today` gates the `past`/`ahead` split behind a visible count ("2 dated changes"), and `now` drives two date-boundary expiry rules that decide whether timeline points render at all. The deck is SSR'd then hydrated, so both run twice against different instants; with Netlify caching the SSR HTML, a response generated before a date boundary and hydrated after it produces different text. This is **the same root cause as [OFFMARKET-DECK-HYDRATION-418] on 2026-07-24**, which fixed it for `computeGainVerdict` by threading a single loader-captured instant. That fix was correct and is still in place — `off-market.$slug.tsx:848` sets `asOfMs: Date.now()` with a comment naming React #418 explicitly, and `HeroSection.tsx:46-59` carries a ⚠ warning to use it. `WhatsChangedSection` moved into Part 03 on 2026-08-13 and simply never adopted it, which is why the rate steps in the week after.
**Fix:** Both call sites now read `new Date(data.asOfMs ?? Date.now())` — the same instant the server used, threaded through serialized loader data — matching the established pattern in the sibling components. Comments at both sites explain why, and name this recurrence so the next person adding a section to this file sees it.
**Files:** Feilds_Website/01_Website/src/pages/OffMarketPage/v4/WhatsChangedSection.tsx
