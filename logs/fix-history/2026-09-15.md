# Fix History — 2026-09-15

## [OFFMARKET-V5-ANALYTICS-DARK] V5 off-market page shipped with no reading telemetry — HH:MM AEST
**Symptom:** Will asked for a deep dive on how people interact with /off-market V5 — where they drop off, where they spend time, and whether the founder videos (added 2026-09-12) had any views. PostHog showed only ~15 views/day of traffic but **no way to answer drop-off or time-on-page**: V5 fired zero view/scroll/section/exit events. Confirmed live: scroll_depth on /off-market collapsed from 68–150/wk (V4 era) to 0–10/wk the week V5 became default (2026-08-21); `offmarket_v4_view` and `v4_report_exit` went to a literal 0. Founder videos: 0 plays and 0 opens anywhere since going live (instrumentation verified correct — genuine zero, not a bug: low traffic × deep placement × ~25s median session).
**Root cause:** When V5 (`v5/OffMarketV5.tsx`) replaced V4 as the default off-market experience on 2026-08-21, it never ported V4's `useReportAnalytics` hook. V5 fired only a handful of discrete click events (`offmarket_market_article_open`, the video events) and NO page-view, scroll-depth, per-section dwell, or exit telemetry, and registered no `offmarket_arm` super-property. The V4 hook could not be reused verbatim because it derives its section order from V4's `PARTS` structure, which V5's flat rail ladder does not have. **Second occurrence of this class** — see [OFFMARKET-DECK-ANALYTICS-DARK] (DiscoveryDeck shipped analytics-dark the same way). A new off-market arm going live without carrying its telemetry is now a repeat pattern.
**Fix:** Wrote `v5/useV5Analytics.ts`, a V5-specific port of the V4 hook, and wired it into `OffMarketV5`. Emits `offmarket_v5_view` (mount, with valuation_method/decline_reason/has_range/n_comps so full and directional pages never pool), `scroll_depth` (page:"offmarket_v5", milestones 10/25/50/75/90/100, reusing the deck/V4 schema), `v5_section_read` {section,index,ms} (midpoint attribution → per-section times sum to session total; ≥1500ms floor), and `v5_report_exit` (sendBeacon: max_scroll_pct, engaged_seconds, wall_seconds, deepest_* vs exit_*, scrolled_back, seconds_by_section). Registers `offmarket_arm:"v5"` and unregisters on cleanup. SECTION_ORDER maps V5's ten ladder sections by DOM id (hero → v5-near → v5-new → v5-valuation → v5-market-update → rail-market → rail-news → rail-yourhome → v5-downloads → v5-founder-video), so the "Why I built Fields" video section reach is now measurable. Keeps the deep-scroll (>50%) Telegram beacon to `/api/v1/offmarket-intent-alert` (the function already accepts `deep_scroll` arm-agnostically — no server change). LAYOUT_VERSION="2026-09-15" + auto SECTION_SIG guard.
