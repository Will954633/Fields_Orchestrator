## [FIELD-NAME-GUESS-FALSE-ABSENCE] "No aerials exist" — a guessed field name reported as missing data — 08:30 AEST
**Symptom:** A query for `aerial_image_url` returned zero documents, and the zero was reported to Will as a fact about the database: no aerial imagery exists. **14,531 documents had one.** The field had simply never been called that — the data lives at `satellite_analysis.satellite_image_url` (plus `domain_hero_image_url`, `scraped_data.images[].url` and 22 other image paths in `Gold_Coast.robina` alone).
**Root cause — two layers, and the second is the one that matters:**
  1. **Behavioural:** a field name was invented from intuition rather than read from a document, and an empty result set was then treated as evidence about the data instead of evidence about the name. A zero result is only ever a statement about the question asked.
  2. **Structural — the safeguard could not have caught it.** `SCHEMA_SNAPSHOT.md` exists precisely to prevent this and instructs "read before writing ANY MongoDB query", but `generate_schema_snapshot.py` sampled each collection with `collection.find({}).limit(5)` — the **five oldest documents, not a random draw** — and walked only the top level, capping nested objects at 10 subkeys with no ellipsis and never expanding arrays of objects. In `Gold_Coast.robina` (12,092 docs: mostly cadastral stubs, a few hundred enriched listings) the first five documents are all one shape, so the file listed **75 fields where live listings carry 233 top-level keys and 2,523 total paths** — and the omission was biased toward exactly the enrichment fields anyone would ask about. It also recorded no fill counts, so a field present on 1 document and one present on all of them were indistinguishable. Following the existing rule to the letter would have produced the same wrong answer.
  3. **Vocabulary gap (why an index alone is insufficient):** even with a complete index, `grep -i aerial SCHEMA_PATHS.tsv` returns **1 irrelevant hit** — this schema says *satellite*. Searching the index for your own guessed word just confirms your own assumption.
**Fix — three layers:**
  1. **`shared/doc_shape.py` (new)** — one walker shared by the generator and the probe so they can never drift: random `$sample` instead of `.limit()`, full recursion through nested objects and arrays (`transactions[].price`), a fill count on every path, dynamic-key maps collapsed to `<dynamic>`, hard path ceiling.
  2. **`generate_schema_snapshot.py` (rewritten)** — now emits two artifacts. `SCHEMA_SNAPSHOT.md` (628KB, down from 969KB) is readable orientation: top-level fields with fill counts. `SCHEMA_PATHS.tsv` (5.3MB) is the complete greppable index — **67,066 paths across 335 collections**, one per line, all depths. Wrapped in `job_run("schema_snapshot", cadence_hours=24)` per Rule 7, with a **7b assertion**: raises if it documents 0 collections, or if path coverage drops below 60% of the previous run, rather than silently overwriting a good snapshot with a blind one. Runtime 37s.
  3. **`scripts/db_fields.py` (new)** — the probe. `--find TERM` searches every database and **expands the term into the vocabulary this schema actually uses** (aerial→satellite, photo→image, coords→georeference), so `--find aerial` surfaces the whole `satellite_analysis` subtree and prints "no path is actually named 'aerial'". `--check FIELD` makes a zero self-refuting: on zero fill it prints every related path that *does* exist in the same output and exits non-zero, so an absence and its rebuttal cannot be separated. `--grep`, `--query` (scope to `listing_status: for_sale`), `--min-fill`.
  4. **CLAUDE.md Rule 8** added to both copies — never infer absence from a guessed name; report a zero as a wrong name, not as missing data.
**Files:** `shared/doc_shape.py` (new), `scripts/db_fields.py` (new), `generate_schema_snapshot.py` (rewritten), `CLAUDE.md` + `/home/fields/CLAUDE.md` (Rule 8), `.gitignore` (ignore the two generated artifacts).
**Recurrence:** **5th in this class, 2nd sub-class.** Wrong/assumed field names: [VALUATION-FLOOR-001] (systemic `floor_area_sqm` mismatch), [VALUE-DRIVERS-SCHEMA] 2026-02-28 (NPUI read `pvd.interior`, which does not exist), [YOURHOME-PHOTO-SCHEMA] 2026-06-02 (resolver written against invented mock shape; its own lesson was *"verify resolvers against a real document"*), [BEDS-BATHS-BACKFILL].
