## [MCE-AGENTIC-OUTPUT] Deep-research child reported "saved the file" instead of returning the dossier — 06:35 AEST
**Symptom:** Stage 4 failed twice — the `claude -p` child returned an 86-char then a 2,650-char
conversational summary ("Refreshed and saved in place at `topics/…`. Want me to push it?") instead
of the dossier markdown. Rule-7b assertion correctly caught it ("implausible dossier, not writing").
**Root cause:** the research child is the Claude Code CLI. Given an existing dossier and "revise in
place" phrasing, it behaved agentically — believed it had edited the file and reported completion —
rather than returning the document as its reply (it has no write tool; the parent writes files).
The proven `run_research_cycle.py` avoids this only via a terse "just return the markdown" line;
the richer MCE prompt reintroduced the ambiguity.
**Fix:** added an explicit `OUTPUT_DISCIPLINE` constant (no write access; do not claim to save;
entire reply must be the document, first char onward) to `mce_common.py`; reworded the Stage-4
prompt away from "revise in place" to "output the full updated dossier text"; raised max_turns
34→50; applied the discipline defensively to Stages 3 and 5. Re-ran → clean 22,500-char dossier.
Also added raw-output capture on validation failure so future short-output failures are diagnosable.
**Files:** `scripts/mce_common.py`, `scripts/mce_stage4_research.py`, `scripts/mce_stage3_psychology.py`, `scripts/mce_stage5_suburb.py`
**Recurrence:** First

## [MCE-QA-TRIPWIRE] Reliability QA tripwire raised false positives on the sentences enforcing the rule — 06:45 AEST
**Symptom:** Stage 8 QA raised 4 "possible QoQ move narrated off unreliable quarter" warnings. All
false: the flagged text was either the guard itself ("Q1→Q2 2026 drop **must not** be reported as a
real fall — both quarters unreliable") or a *volume* drop ("sales dropped to 50"), which the
reliability flag does not govern (it governs *price* QoQ only).
**Root cause:** the tripwire fired on any direction word (fell/dropped) within 120 chars of an
unreliable-quarter mention, with no awareness of negation context or price-vs-volume.
**Fix:** widened the window to 200 chars; suppress when a guard phrase (must not / do not / did not
/ unreliable / noisy / not real …) is present; and require a `$#####` figure near the direction
word so only *price* moves trip it. Re-ran → 0 errors / 0 warns, while a genuine "median fell from
$X to $Y" (no guard) still trips.
**Files:** `scripts/mce_qa.py`
**Recurrence:** First
