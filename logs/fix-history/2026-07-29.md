## [OFFMKT-RL-DECK-EXIT] deck_exit instrumentation never firing — 14:17 AEST
**Symptom:** Zero `deck_exit` events in PostHog despite 210 `card_viewed` events and 104 `$pageleave` events on /off-market/ pages. Phase-0 RL dense instrumentation blind.
**Root cause:** `deck_exit` was emitted in a React `useEffect` cleanup function (`return () => emit(...)` in `useEffect(()=>{...}, [])`). React cleanup is unreliable on tab close — the browser tears down the page before React can flush the event via the PostHog batch queue. PostHog's own `$pageleave` works because it hooks `beforeunload` internally; custom `capture()` in cleanup goes through the standard batch queue which dies on unload.
**Fix:** Replaced React cleanup with `visibilitychange` event listener (`document.visibilityState === "hidden"`) + PostHog `sendBeacon` transport (Navigator.sendBeacon survives page unload). Also emits final `card_dwell` with `direction: "exit"` for the current card (previously lost since card_dwell only fired on swipe-away). Uses ref pattern (`exitFnRef.current`) updated every render so the handler reads current state.
**Files:** Feilds_Website/01_Website/src/pages/OffMarketPage/OffMarketDeck.tsx (commit 3c4fdc55).
**Recurrence:** First.
