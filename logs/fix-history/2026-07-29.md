
## [SEO-HFS-CANON] /houses-for-sale/<suburb> case variants not canonicalized — 
**Symptom:** Both `/houses-for-sale/robina` (lowercase) and the canonical `/houses-for-sale/Robina` returned HTTP 200 serving the same listing set — duplicate-content risk. The canonical tag pointed to the Title-Case URL but non-canonical case variants were served directly instead of redirecting.
**Root cause:** The route loader resolved the suburb param case-insensitively (`param.toLowerCase()`) and rendered the page for any case, without 301-ing off-canonical slugs to the sitemap/canonical Title-Case form.
**Fix:** Added `throw redirect(\`/houses-for-sale/${resolved.slug}\`, 301)` in the loader when `params.suburb !== resolved.slug`, matching the existing idiom in property.$id.tsx / sold.$id.tsx / market-intelligence.tsx.

## [OFFMARKET-FINDPROPERTY-ALLOWLIST] New-suburb off-market pages rendered thin noindex shell — 12:00 AEST
**Symptom:** After minting 24 valid Nerang off-market docs, `/off-market/54-crusader-way-nerang` returned HTTP 200 but a
generic `noindex` shell (no address, generic title) despite the doc being correct + in the right DB (localhost:27017, same mongod the site reads).
