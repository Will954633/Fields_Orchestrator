## [VALUATION-UNKNOWN-ASYMMETRY] Unknown attributes marked subjects down — 11:35 AEST
**Symptom:** An un-analysed subject was silently valued BELOW comparables that had been
photo-analysed. Worth up to $120,000 on water views alone.
**Root cause:** `water_views`, `cladding_level`, `ac_ducted` and `number_of_stories`
collapsed UNKNOWN to a concrete inferior value ("no view" / brick / not ducted / single
storey) in BOTH `basic_features()` and `calculate_adjustments()`. Same defect class as the
pool default fixed 2026-08-07 (which had penalised ~894 homes ~$75k each). Fixing only the
adjustment layer would have done nothing — `basic_features()` collapses the value first, so
a None-check downstream could never fire.
**Fix:** Guarded both layers; skip the adjustment when either side is unknown. Shipped
BEHIND `VALUATION_UNKNOWN_HARDENING=1`, **default OFF**. A/B on identical data (robina
n=253, full photo-blinding): median AE 7.2%→6.7% (better) but bias +0.7%→+2.1%. The
markdown was cancelling ~1.4% of a systematic OVERvaluation, most of which is the
known-stale suburb calibration (robina 1.0189 where the holdout refit says 1.0058).
Enabling alone would move every stored valuation at the next 20:30 recompute while the live
page publishes accuracy measured under the old behaviour — the situation Will declined
2026-08-10. Ships as one change with the calibration refit + page-table re-derive.
**Verified:** default path unchanged (MAE 9.1% both sides; the $7 delta is harness noise —
two identical runs differ by $6).
**Files:** `Feilds_Website/07_Valuation_Comps/precompute_valuations.py`,
`scripts/valuation_backtest.py`, `16_Valuation/experiments/2026-08-12-unknown-attribute-hardening.md`

## [YOURHOME-FIXTURE-LEAK] Demo property's copy rendered on a real report — 17:20 AEST
**Symptom:** The no_llm build's hero read "only four match your combination of six bedrooms,
dual living, a pool, and a cul-de-sac head against permanent bushland" on a home the same
page listed as 4 bd / 2 ba. The text is `homeFixture.ts:1340` — hardcoded demo copy for a
Merrimac property.
**Root cause:** Two halves. (1) `stubFromDoc()` deep-clones the entire Merrimac fixture
(`TERRACE_COURT_13`) and overlays only the fields the resolver produced, so anything not
overlaid keeps the demo property's content. (2) `HeroSection` gates scarcity copy on
`slotStatus.scarcity === "approved"`, and the `no_llm` path approved that slot while writing
NO headline — so `hero.subhead || hero.headline` fell through to the un-overwritten fixture.
**Fix:** Frontend now requires the copy itself, not the flag
(`scarcityApproved = status === "approved" && scarcityCopy.length > 0`). Resolver now only
approves the scarcity slot when a headline exists. Both halves, because either alone leaves
the trap armed for the next un-overlaid field.
**Exposure:** NOT live — 1 doc, the test build. But it was a hard blocker for the corpus
plan: `no_llm` as the `/your-home` default would have put a false claim in ~15,000 heroes.
**Files:** `Feilds_Website/01_Website/src/pages/YourHomePage/components/HeroSection.tsx`,
`scripts/property_reports/slot_resolver.py`

## [YOURHOME-DETERMINISTIC-PROSE] Scarcity hero + market paragraph templated — 17:25 AEST
**Symptom:** The two prose slots a no_llm build visibly lost (`scarcity` hero and
`market_narrative`) each cost an LLM call, ~10-27s, and could fail.
**Root cause:** Not composition — ordering and joining. `scarcity_features.FEATURE_RULES`
already stores a finished `phrase` per feature; `scarcity_narrative._format_inputs:172-178`
pre-assembled the whole combination string; the sentence frame was dictated word-for-word in
the prompt; the closing line was already a Python constant. `market_narrative` had ten
scalars and a prompt specifying the paragraph beat by beat.
**Fix:** `scarcity_headline.py` and `market_paragraph.py` — deterministic, `method:
"deterministic-v1"`, same output keys so the resolver and frontend are unchanged. Both
return None rather than emit a claim they cannot support (thin feature stack; sub-50-word
market read). Editorial rules are now structural: no forbidden word is in the vocabulary,
the K-of-N receipt can only describe the COUNTED anchors, and every figure is copied rather
than re-derived.
**Verified:** scarcity across 6 real properties; market across 8 suburbs, all 50-90 words,
zero forbidden words, zero advice patterns. Two grammar bugs found and fixed in review —
"a 824-metre walk" (article agreement) and "narrows" with a plural subject.

`slot_resolver.py`
