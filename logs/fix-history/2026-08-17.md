# Fix history — 2026-08-17 (AEST)

## [BRAIN1-VERIFY-CORPUS-GAP] Publish gate blind to 2,126 units — recurred, now self-reporting — 07:30 AEST

**Symptom:** `brain1_verify.py` — the publish gate that decides whether a brief's quotes are
genuine — indexed only part of the graph. Quotes from **Bothsides Podcast (AU)** (1,670 units) and
**KB:book raw-.txt books** (456 units) cannot be located in an index that never loaded them, so
they are reported `NOT_FOUND`, which is the verifier's own word for **fabricated**. Found while
preparing to verify Brain 1 cold-calling briefs, before any brief was written — not from a bad
brief this time.

**Root cause:** `ANN_FILES` in `brain1_verify.py` is a hardcoded list that must be kept in sync by
hand with `BRAIN1_SOURCES` in `brain_drive_nightly.py` and the `--merge` list in `brain1_graph.py`.
The graph grew to 6 sources; the verifier's list still named 4 of them (plus 2 non-graph ones).
Missing: `/home/fields/brain1_build/Spotify/annotations.jsonl` (u8##### podcasts) and
`/home/fields/brain1_books/annotations.jsonl` (k9#### books).

**This is the second occurrence and the third instance of the class.** 2026-08-10 was the same
defect with `brain1_yt` (2,292 units — every `u9#####` id — causing **41 false fabrications in one
129-quote brief**, headline fidelity 64.0% → 96.1% once fixed). The file already carried a comment
block explaining that incident. **A comment telling the next person to update a list is not a
control** — it failed on the very next corpus addition. Same class as
`[BRAIN1-NIGHTLY-REBUILD-DROPS-SOURCES]` and `[BRAIN1-MERGE-SOURCE-LOSS]`: the corpus grows, a
consumer's hardcoded source list does not, and the consumer exits 0 either way.

**Fix:**
1. Added the two missing annotation files to `ANN_FILES`.
2. **Added the missing control** — `warn_index_gap()`, called from `unit_texts()`. It streams
   `(id, lib)` for all 14,256 graph units out of the 41 MB `package.json` with a chunked regex
   (never holding the file in memory), diffs them against the index actually built, and prints a
   loud block naming **each missing library and its unit count** plus the fix. On full coverage it
   prints one confirming line, so "the check ran" is distinguishable from "the check is silent" —
   Rule 7b applied to a read path: the gate now asserts an outcome instead of merely not throwing.

Verified both directions: current config → `index covers all 14256 graph units`; simulating the
pre-fix list → correctly names `1670 Bothsides Podcast (AU)` and `456 KB:book`.

**Why it matters beyond Brain 1:** Bothsides Podcast is one of only two Australian libraries in
the corpus, and the work in flight is Australian cold-calling research. The gap was biased
precisely toward the most relevant material — as in the 2026-08-09 `[FIELD-NAME-GUESS-FALSE-ABSENCE]`
case, where the safeguard's blind spot lined up with the question being asked.
