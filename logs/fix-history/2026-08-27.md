## [OFFMARKET-TRUNCATED-SLUG-404] Suburb-less off-market link 404'd despite report existing — 09:49 AEST

Loader 301s to the canonical slug, preserving the query string so report link keys (?k=) and ?arm= survive. Verified live: broken URL 301→canonical→report renders; ?k=/?arm= preserved; nonexistent street stays not-found. npm run build passed (14.31s); ONE commit be7ca84cb6143ff5e3f8727b95b0d4a2731f8356, md5-verified.
