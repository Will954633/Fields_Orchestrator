# The Fields Quarterly — Developer Handoff

This folder is a self-contained package for a print-focused web developer to rebuild
*The Fields Quarterly* template at production fidelity, matching the designer's system.
It mirrors the package we used for our property-appraisal report job.

## Design constraints to preserve when we parametrise
When the developer's static HTML becomes our data-driven template, these must survive:

- **The giant Conviction-Index number is the hero** (cover + index page). It varies 2–4 characters (e.g. `94.4`, `103.0`, `98.6`) — the layout must hold at each width without reflowing the page.
- **The "F"-pillar photo device** on the cover/back — B&W duotone photography masked into the Fields "F" / staggered rounded-top shapes. Signature element. Must render in the **actual PDF** (headless Chrome drops raw CSS `mask-image` — use pre-rasterised masked images or inline-SVG `<clipPath>`/`<mask>`).
- **Photography aspect ratios** — cover device is portrait ~0.63:1; property-story photos are landscape ~1.42:1 (`object-fit: cover`); back cover is full-bleed A4. Keep these fixed so swapped images never distort.
- **Variable counts** — a quarter may have 3–5 charts, 4–8 property stories, and commentary of varying length. Cards use `min-height`, not fixed height; `page-break-inside: avoid` on each.
- **Fonts** — Playfair Display (display + number) + Poppins (uppercase labels). Explicit weights.
- **Palette tokens** — birch `#E6DDD2`, copper `#B76749`, teal `#A0D1C9`, grass `#22382C`, charcoal — as CSS variables at the top of the stylesheet.
- **Footer** — "SMARTER WITH DATA" + Fields F-mark on each page; "FIELDSESTATE.COM.AU/QUARTERLY" on the cover.
- **Editorial rules for content** (so placeholder copy reads right): no advice, no forecasts, exact prices (`$1,250,000` not `$1.25m`), suburbs capitalised.

## Our pipeline (context, no action needed from the developer)
The finished HTML is wired into `10_Market_Report/pipeline/` — charts are generated by
`generate_charts.py`, the Conviction Index by `fci_calculator.py`, and the whole thing
renders to PDF via headless Chrome. The developer delivers static HTML/CSS + a sample PDF;
we parametrise and wire it in.
