# Published accuracy figures — measured 2026-08-07

**These are the numbers we are allowed to publish.** Anything not on this page has not been measured
under the current method and must not be quoted.

---

## How to reproduce, exactly

```bash
source /home/fields/venv/bin/activate
set -a && source /home/fields/Fields_Orchestrator/.env && set +a

# ON-MARKET figure (subject has marketing photos)
python3 scripts/valuation_backtest.py --price-filter none --property-type House \
  --min-price 1000000 --max-price 2000000 --suburb <suburb> --dump-errors /tmp/out.json

# OFF-MARKET figure (subject has none) — use this for anything about the off-market report
python3 scripts/valuation_backtest.py --price-filter none --property-type House \
  --min-price 1000000 --max-price 2000000 --suburb <suburb> --blind-subject \
  --dump-errors /tmp/out.json
```

Run per suburb, then pool. **`--price-filter none` is mandatory** — the default prunes comparables
using the subject's own sale price (target leakage). Attached dwellings are excluded by default.

**Sample:** n = 588 detached houses, $1,000,000–$2,000,000, Robina + Varsity Lakes + Burleigh Waters.

## The figures

All de-biased per suburb, so they measure spread rather than offset.

### Off-market subject — **use these for the off-market product**

⚠ **Superseded twice on the same day.** The 8.92% figure was measured before the geometry-led cohort
change, and with a backtest that had drifted from production (its own `in_cohort`, no
`apply_retired_adjustments`). Both are fixed; these are the current numbers.

| | n | MAE | median error | within 10% | 80% band on $1.6M |
|---|---|---|---|---|---|
| before this work | 588 | 9.93% | 7.66% | 62% | $521,773 |
| after calibration + retirement | 588 | 8.92% | 6.86% | 65% | $457,572 |
| **final — geometry-led cohorts, backtest synced** | **581** | **8.76%** | **7.13%** | **66%** | **$437,755** |

**Published half-width: ±13.7%.** Suburb offsets re-derived on the same run: Robina 1.0194,
Burleigh Waters 1.0256, Varsity Lakes 1.1338.

### Against where this investigation started

The original measurement, before attached dwellings were excluded and before the proximity
adjustments were wired into the backtest, was **MAE 10.83%, within-10% 59%, 80% band $603,574**.

**$603,574 → $437,755** on the off-market product, a 27% narrower band, with MAE 10.83% → 8.76% and
within-10% 59% → 66%.

## What produced the improvement

| change | contribution |
|---|---|
| per-suburb calibration | largest single win — Varsity Lakes runs −11.8% against Robina's −2.3% |
| retiring kitchen / renovation / renovation_quality | −0.25 to −0.40pp MAE each |
| excluding attached dwellings | corrects a class that ran MAE 18.0% against 10.3% |

## ⚠ What was tested and did NOT work — do not retry

| tried | result |
|---|---|
| adaptive band width by comp dispersion | ±17.0% average against ±16.4% flat — pooling wins |
| fewer, higher-quality comparables | best-3 ±18.4% against all-8 ±16.9% — more is better |
| refitting all 19 adjustment multipliers | ±15.5% against ±15.6% for a 3-attribute drop, and in-sample |
| rescaling beach ×1.5 and street ×1.25 | **worse in both populations** — the scoped calibration did not generalise |
| blending toward the raw-comp median | ±18.2%, marginal |

## ✅ Fixed since first writing

**Water views were being valued as waterfront.** Closed the same day — OSM water geometry backfilled
to 100% coverage and `classify_water_relationship()` wired into cohort selection. See
`experiments/2026-08-07-water-geometry-backfill.md`.

## ⚠ Known, unfixed, and material

**Subject and comparables are measured on different floor-area rulers.** Off-market subjects resolve
to internal-living 47.9% of the time; their sold comparables resolve to `building_fallback`
(internal + garage) 41.6% of the time, and the two metrics differ by a median **17.8%**. On the
largest adjustment in the method. Also 48.7% of off-market homes resolve to no floor area at all.
See `experiments/2026-08-07-enrichment-contribution-scoping.md` — this is now the largest known
remaining defect.

**Superseded — was: water views valued as waterfront.** 69% of homes flagged waterfront are not
waterfront by geometry, and they run median error +10.4%, MAE 14.9%, 78% over-valued.
`classify_water_relationship()` exists and is correct, but **53% of homes have no OSM
`water_features` block**, so it cannot yet be the cohort authority. Backfilling that pass is the
single largest remaining accuracy win. See `methodology/04-water-and-cohorts.md`.

`9 Laura Place, Varsity Lakes` is the live example: still valued at $1,951,982 against a $1,298,000
sale after all corrections, because it is a lake-view home pooled against water-frontage comparables.

## Standing obligation

**80% coverage is a promise.** Re-measure after any method change. If coverage drops below 80%, the
band widens — it does not get quietly left alone. The half-width lives in
`precompute_valuations.py::_EMPIRICAL_80_BAND_PCT` and is an output of this measurement, not a
constant to tune.
