# Published accuracy figures — measured 2026-08-08 (CURRENT)

**Supersedes `2026-08-07-figures.md`.** These are the only figures we are allowed to publish.

---

## Reproduce

```bash
source /home/fields/venv/bin/activate
set -a && source /home/fields/Fields_Orchestrator/.env && set +a

python3 scripts/valuation_backtest.py --price-filter none --property-type House \
  --min-price 1000000 --max-price 2000000 --suburb <suburb> --blind-subject \
  --dump-errors /tmp/out.json
```

Run per suburb, then pool. **`--price-filter none` is mandatory** (the default prunes comparables
using the subject's own sale price — target leakage). **`--blind-subject` is mandatory for anything
quoted about the off-market product** (sold subjects carry photo-derived attributes that off-market
homes never have). Attached dwellings are excluded by default.

**Sample:** n = 581 detached houses, $1,000,000–$2,000,000, Robina + Varsity Lakes + Burleigh Waters.

## What produced the improvement

| change | effect |
|---|---|
| adjustment reliability shrinkage (λ=0.80) | largest single win — band 13.7% → 12.2% |
| computing from the full candidate pool | homes selling above every comparable 42% → 4% |
| per-suburb calibration | Varsity Lakes runs −11.1% against Robina's −1.9% |
| retiring kitchen / renovation / renovation_quality | −0.25 to −0.40pp MAE each |
| geometry-led water cohorts | fixed a class running +10.4% median error, 78% over-valued |
| excluding attached dwellings | that class ran MAE 18.0% against 10.3% |

## ⚠ Tested and REJECTED — do not retry

| tried | result |
|---|---|
| adaptive band width by comp dispersion | ±17.0% average against ±16.4% flat — pooling wins |
| fewer, higher-quality comparables | best-3 ±18.4% against all-8 ±16.9% |
| nearest-8-by-distance selection | MAE 10.27% against 8.76% |
| refitting all 19 adjustment multipliers | no gain over a 3-attribute drop, and in-sample |
| rescaling beach ×1.5 / street ×1.25 | worse in both populations |
| satellite analysis as an accuracy lever | 9.09% with against 9.20% without |
| photo-derived quality attributes | blinding the subject *improved* MAE |
| floor-area "ruler mismatch" | r = +0.027 against error, despite a real 17.8% metric gap |

## The noise floor, and what remains

Leave-one-out inside the comparable set: our comparables agree with **each other** within ±8.3%, so
averaging ~8 of them should give ±3.0%. We deliver ±12.2%. **The method is precise but not
accurate** — the comparables agree and are collectively displaced.

Part of that agreement was manufactured (we selected for it — now fixed). The remainder is a
per-property displacement that survived every intervention tried. **The only untested candidate is
the class of attributes we hold no data on for any property: aspect, outlook, slope, frontage width,
noise exposure.**

⚠ Also real and unaddressed: **48.7% of off-market homes resolve to no floor area at all** — the
largest adjustment in the method, missing on half our subjects.

## Standing obligation

**80% coverage is a promise.** `_EMPIRICAL_80_BAND_PCT` and `_ADJUSTMENT_RELIABILITY` in
`precompute_valuations.py` are **outputs of this measurement**, not constants to tune. Re-derive both
after any method change. If coverage falls below 80%, the band widens.
