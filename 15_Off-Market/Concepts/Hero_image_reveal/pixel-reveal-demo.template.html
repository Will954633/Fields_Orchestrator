The delay field

Every cell gets a start time from its distance to the origin — blended between a diagonal projection (straight wall) and true radial distance (bloom), then jittered by Scatter.

Resolving, not fading

The image is pre-rendered at a stack of pixelation levels. A cell walks down that stack as its own clock runs, so it sharpens from coarse blocks to full detail rather than just fading in.

Cheap per frame

Finished cells are blitted once into a settled layer. Each frame draws that layer plus only the cells currently in flight — so block size barely affects frame cost.

// per-cell start time — this is the whole effect
const dx = cx - originX, dy = cy - originY;              // pixels from origin
const diag   = (dx * dirX + dy * dirY) / diagSpan;      // straight front
const radial = Math.hypot(dx, dy) / radialSpan;        // circular bloom
let   d      = diag + (radial - diag) * shape;          // blend the two
      d     += (rand() - 0.5) * scatter;                // break the edge
cell.start = clamp01(d) * (1 - trail);

// per frame, for cells with 0 < p < 1
const e   = easeOutCubic(p);
const mip = MIPS[Math.min(LEVELS - 1, (1 - e) * LEVELS | 0)];
ctx.imageSmoothingEnabled = false;
ctx.drawImage(mip.cv, x / mip.b, y / mip.b, w / mip.b, h / mip.b, x, y, w, h);   // 64px blocks -> 1px
